Label-reader design partners

For people who turn the package around

Ingredio is building a personal Label Library for people who already read ingredient lists. We are looking for a small group willing to test whether it helps them remember what they read across real shopping days.

Does this describe something you actually do?

  • You read the ingredient list before deciding on a packaged food.
  • You have searched an unfamiliar term, saved a package photo, or compared two labels.
  • You sometimes have to repeat the same label research on a later shopping trip.

If none of these happened recently, this research is probably not for you—and that is useful qualification, not a judgment.

The three-label trial

  1. Choose three real packages already at home. Start from labels you would genuinely read.
  2. Use Ingredio to record what you notice. Add Watchlist terms only if you choose to.
  3. Return on another day. Revisit or compare a saved label when a new package creates a real question.

What we want to learn

  • What was the last ingredient label you read, and what did you do with that information?
  • Did a saved label reduce the need to start over later?
  • Did the Watchlist reflect your choices without feeling like a universal verdict?
  • What would make the Label Library worth returning to—or clearly not worth it?
